\chapter{Java Typestate Checker}

\textbf{Java Typestate Checker}\cite{jatyc:github} es una herramienta de verificación de código Java para protocolos de objetos. Analizando el programa en forma estática, detecta errores relacionados al orden de las llamadas a métodos, consumo debido de los recursos y herencia de protocolos, entre otras cosas. La herramienta está escrita en Kotlin\cite{kotlin} como plug-in del Checker Framework\cite{checker-framework}, y se destaca por ser una de las herramientas de verificación de object protocols más flexibles y actualizadas para Java.
